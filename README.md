# 大老二小助手

神來也大老二的出牌建議小幫手。用 iPad（iPadOS 27 的 Safari）打開網頁、分享螢幕，它會一直讀牌桌、記下每家出過的牌，輪到你時自動在畫面上顯示建議。

網址：https://aboveorchids-hue.github.io/big2-helper/

## 怎麼用
1. 遊戲和 Safari 分割畫面（或台前調度兩個視窗並排），遊戲視窗要完整露出來。
2. 按「開始讀螢幕」，選擇分享螢幕。
3. 輪到你時，建議會自動出現；開新的一局時它會自己認出來，認錯了就按「新的一局」。
4. 建議出現時會響一聲：要出牌是兩聲「叮咚」，PASS 是一聲低音。不想聽就把「有建議時發出提示音」取消勾選。iPad 側邊的靜音開關打開時不會響。
5. 遊戲跳出「您沒有更大的牌可出」時，會直接顯示 PASS。

## 換牌局
- 在換牌場玩時，勾選「換牌局（每局開始先換 0～3 張）」。勾一次就好，會記住。
- 每局一發牌，建議會先顯示要換哪幾張（或不換），還有照這樣換和不換各自平均每局幾分。
- 算法：每種換法（0～3 張，共 378 種）先快速比一輪，再把最好的十幾種和「不換」用同一批牌局完整模擬打到結束：至少 200 局，每 100 局把落後最好的換法超過 2.5 個標準誤的淘汰，只剩一種、到 3000 局或算了 3 秒就停（和出牌建議同一套；這些數字可以在「進階設定」改）。別家的手牌照還沒看到的牌隨機發，別家假設會換掉 3～10 之間落單的小牌，換出的牌洗在一起再隨機補回。
- 試過 24 手牌（每種換法再各模擬 3000 局當標準答案）：以前在 100、400 局時固定只留前 6、前 3 種，平均每局比最好的換法少約 0.6 分，現在約 0.3 分；算的時間從約 0.8 秒變約 2.4 秒。
- 換牌很值得：別家都換落單小牌時，你不換平均每局少 5～7 分；照建議換比「換掉落單小牌」再多約 0.6～1.2 分（b11 的換牌建議測的，各 800 局）。
- 換完後它會比對手牌，記下你換出、換到哪幾張（點開「記牌」看得到）。換出去沒換回來的牌在別家手上。
- 換牌時，你的牌列變少、別家張數先變少再回到 13，都不會被當成出牌；各家都回到 13 張就算換完。換牌時畫面上的按鈕也不會被當成輪到你出牌。你拿到梅花 3、要先出時，換完就會給出牌建議。

## 記牌
- 每家出牌時，遊戲會在那一家旁邊把牌放大顯示（有黃色光框，老二還有獎章）：從這裡直接讀出是誰、出了哪幾張，單張、一對、五張牌都讀。
- 各家剩幾張讀牌扇上的數字圓章，PASS 讀那一家旁邊的金色字樣。
- 桌子中間的單張也會讀，當作備用。
- 這些都拿來算建議（還沒出現的牌、每家剩幾張、要壓的是哪一手）；想確認時，點開「記牌」可以看各家出過的牌和還沒出現的牌。
- 新的一局會自己認出來（看到另一副 13 張手牌時）；按「新的一局」也可以。

## 建議怎麼算
- 「建議依據」可以選「神幣優先」（平均每局分數最多）或「勝率優先」（先出完的機率最高），出牌和換牌建議都照這個選，會記住。
- 每種出法都把還沒出現的牌照各家張數隨機發下去，模擬打到結束，每種出法都用同一批發牌比較。至少 200 局，每 100 局檢查一次：落後最好的出法超過 2.5 個標準誤的就淘汰，只剩一種、到 1500 局或算了 2 秒就停（這些數字可以在「進階設定」改，見下面）。明顯的局面很快算完，差不多的局面會算到 1500 局。
- 試過 158 個局面：固定 300 局時，約 0.9% 的決定會少掉 3% 以上的勝率；現在這樣幾乎沒有，花的時間平均約原來的 1.5 倍。
- 算分照這款遊戲：輸家依剩幾張扣分，10 張以上、手上留著 2、鐵支、同花順都加倍；贏家最後一手是 2 等會加倍；贏家拿到的扣 15% 抽水。
- 模擬比以前快約 1.9 倍（同樣的局數選出的出法完全一樣，比過 15,375 手和 204 次建議），2 秒內算得到的局數比較多。

## 進階設定（模擬幾局、算多久）
點開「進階設定」可以自己改模擬的數字，出牌建議和換牌建議各一組，改了會記住，也會馬上照新的值重算畫面上的建議；按「恢復預設」回到原來的值。有改過時，「進階設定」旁邊會標「已自訂」，「複製紀錄」也會附上目前的設定。

| 欄位 | 意思 | 出牌預設 | 換牌預設 | 可填 |
|---|---|---|---|---|
| 淘汰門檻（標準誤） | 落後最好的一種超過幾個標準誤就淘汰；越大越不會誤刪，算得越久 | 2.5 | 2.5 | 0.5～10 |
| 至少幾局 | 算到這麼多局才開始淘汰 | 200 | 200 | 10～20000 |
| 最多幾局 | 算到這麼多局一定停 | 1500 | 3000 | 10～20000 |
| 每幾局檢查一次 | 多久檢查一次要不要淘汰、停下來 | 100 | 100 | 1～5000 |
| 時間上限（毫秒） | 超過就停，1000 毫秒＝1 秒 | 2000 | 3000 | 100～20000 |

- 「至少幾局」不能比「最多幾局」多，「每幾局檢查一次」也不能比「最多幾局」多（不然一種都不會淘汰、也不會看時間，每種都算到最多）。填的值不合時欄位會變紅、寫出原因，還是用上次的值。
- 出牌建議時間到了也會先算完「至少幾局」，之後每次檢查時才看時間；換牌建議先算滿 60 局，之後時間一到就停。
- 算的時候這頁停著不讀螢幕，時間設太長，讀牌會跟著慢。

## 建議有多強
用 `test/match.js` 模擬整局對打：你這家照某種打法，另外三家是電腦；每副牌讓你輪流拿四家的手牌各打一次，各種打法都打同一批牌，算分照這款遊戲（含抽水）。四家一樣強時，每家平均每局約 −1.2～−1.8 分（抽水）。

平均每局得分（各 400 局）：

| 別家 | 只用權重型打法（不模擬） | 照建議打 |
|---|---|---|
| 規則型（建議模擬時假設的別家打法） | +9.0 | +18.4 |
| 新手型（能壓就出最小的） | +2.4 | +7.5 |
| 一半規則型、一半權重型 | +2.8 | +7.0 |
| 權重型、四分之一的時候隨便選前幾名 | +0.9 | +2.2 |
| 權重型（比規則型強） | −1.2 | +0.9 |
| 會模擬的高手（小版本的出牌建議） | −2.2 | −1.2 |

- 對上哪一種別家，照建議打都比不模擬好；別家越接近規則型，贏越多，別家越強，優勢越小。
- 試過但沒有變強的改法（各 400 局，和現在比）：
  - 每次比 16 種出法（現在 8 種）：−0.3～+0.1 分。
  - 從別家的 PASS 推他的牌（例如剩一張的人沒壓你的單張，那張一定比較小）：幾乎不改變建議（±0.0）。
  - 模擬時把別家當成權重型：對上權重型 +1.3、有時隨便選的 +0.9，對上規則型 −4.9；一半一半：+1.2、−0.5、−1.6。看別家像哪一種，沒有一種都比較好。
  - 重調權重型的權重：自己直接打，對各種別家多 0.4～2.1 分；但拿來當模擬裡你後面的打法，建議反而少 0.1～4.8 分。
  - 如果看得到別家的牌：別家是規則型時多 25 分，別家是權重型時只多 0.4 分、有時隨便選的反而少 1.2 分。
- 所以出牌建議的瓶頸是「別家會怎麼打」猜得準不準，不是模擬局數或比幾種出法。

## 隱私
螢幕畫面只在你的 iPad 上辨識，不會上傳到任何地方。

## 內容
- `read.js` 讀牌桌（和截圖版「大老二出牌助手」同一套讀法），`models.js` 讀牌模型和策略權重。
- `state.js` 記錄牌局，`live.js` 把連續讀到的畫面變成牌局、算建議，`engine.js` 出牌 AI。
- `swap.js` 換牌局要換哪幾張。
- `test/sim.js`：用模擬的牌局測記牌和建議（`node test/sim.js 80`；換牌局 `SWAP=1 node test/sim.js 40`）。
- `test/match.js`：模擬整局對打，測建議有多強（`node test/match.js 100 smart s pimc`：100 副牌、別家規則型，比只用權重型打和照建議打；別家可以是 `smart`、`s`、`mix`、`noisy`、`greedy`、`pimc`；換牌局 `SWAP=1 node test/match.js 200 smart s:swap=none s:swap=advice`）。
- 出問題時，展開「紀錄」按「複製紀錄」，必要時按「存下目前畫面」。紀錄在重新整理網頁後還會保留 3 小時。
